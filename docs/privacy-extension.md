# md-reader Browser Extension — Privacy Policy

_Last updated: 2026-06-10_

The md-reader browser extension runs entirely in your browser.

- **No data collection.** The extension does not collect, transmit, or sell any
  user data. There are no analytics, no tracking pixels, and no remote calls.
- **Content access.** The extension reads the text of markdown files on the
  code-hosting sites listed in its permissions (GitHub, GitLab, Bitbucket,
  Gitea) solely to render the reading view you ask for. Content never leaves
  the page.
- **Storage.** Reading preferences (theme, font size) are stored locally via
  `chrome.storage` and never transmitted.
- **Contact.** Questions: open an issue at
  https://github.com/manup-dev/themarkdownreader/issues
