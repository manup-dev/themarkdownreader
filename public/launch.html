The three artifacts

One document. Three ways to understand it.

🎙️

AI Podcast

Two AI voices (Kokoro-82M, running on your GPU) discussing your document in natural conversation. 2-minute quick take or 10-minute deep dive. Works offline.

🧠

Mind Map

Instant visual outline of your document's structure. Zoom, pan, and click any node to jump to that section. Great for getting the lay of the land before diving in.

🎓

AI Tutor

A personal coach that explains each section, quizzes your comprehension, and remembers what you struggle with. Like a 24/7 tutor for any document you drop in.

For developers using Claude Code, Cursor & Copilot

Read the spec. Ship the prompt.

md-reader is where your reading loop meets your coding loop. Select any passage in a spec, RFC, or design doc → leave a comment → one-click generate a Claude-ready prompt with accurate line references → one-click send it to your VS Code terminal where claude is already running.

# Generated by md-reader

In the file `spec-v2.md`:

## Requested changes

### Section: "Token refresh flow" (L142)
> "The client MUST retry with exponential backoff
>  up to 5 attempts before surfacing an error..."

**Change:** Implement the retry helper in src/auth/refresh.ts.
Use the existing withRetry() util. Add a test for the 5th-attempt
failure path. Don't swallow the error after the final retry.
